System Administrator Console (/admin)

Accessible strictly to accounts with role = 'admin'. The bootstrap admin email is seeded on startup from APP__ADMIN__EMAIL.

Console Tabs
  • Users: Search accounts, inspect workspace counts, and promote/demote system roles.
  • Hot Support: Launch an isolated impersonation session via the dedicated hot-support-session cookie without overwriting your admin login.
  • Test Accounts: Provision Argon2id password-enabled accounts (is_test_account = true) for automated Playwright E2E and QA login at /auth/login-password.
  • Global Notifications: Publish rich HTML announcement banners targeted to all, authenticated, or admins with per-user read tracking.
